# 🐝 Invitación Sorpresa

Mini web romántica — lista para publicar en GitHub Pages.

---

## ¿Cómo publicarla en GitHub Pages?

### Paso 1 — Crear el repositorio

1. Ve a [github.com](https://github.com) e inicia sesión (o crea una cuenta gratis).
2. Haz clic en **"New repository"** (botón verde arriba a la derecha).
3. Ponle un nombre, por ejemplo: `cita` o `para-ti` *(este nombre aparecerá en la URL)*.
4. Déjalo en **Public**.
5. Haz clic en **"Create repository"**.

---

### Paso 2 — Subir el archivo

En la página del repositorio vacío:

1. Haz clic en **"uploading an existing file"**.
2. Arrastra el archivo `index.html` a la ventana.
3. Haz clic en **"Commit changes"** (botón verde abajo).

---

### Paso 3 — Activar GitHub Pages

1. Ve a **Settings** (pestaña arriba en el repo).
2. En el menú izquierdo busca **"Pages"**.
3. En **"Branch"** selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **"Save"**.

---

### Paso 4 — Obtener el link

Espera ~1 minuto y recarga la página de Settings > Pages.  
Verás algo así:

```
🎉 Your site is live at https://TU_USUARIO.github.io/NOMBRE_REPO/
```

Ese link es el que le mandas a él 💛

---
